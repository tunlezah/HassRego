# HassRego

A Home Assistant custom integration for checking Australian vehicle
registration status.

Enter the registration number and state or territory for each of your
vehicles, have them checked automatically on a schedule, and drive
automations — a notification, a light — off the result.

See the [issue tracker](https://github.com/tunlezah/hassrego/issues) for
current status.
